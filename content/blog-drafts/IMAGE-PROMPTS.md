# Cover image prompts — Nature Kingdom blog

Each prompt below is complete and self-contained. Copy one, paste it into your image
generator, done. No assembly needed.

**Export each result as:** 1920x1080 (or 1600x900) JPEG, sRGB, landscape 16:9.
Keep the main subject in the top two-thirds — the site fades the lower third to near-black.
The same file doubles as the 1200x630 social share image.
Upload via the Cover Image field in the post editor.
